# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately**, not through public issues
or pull requests.

Use GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/pkalisiewicz/improv-toolbox/security/advisories/new).

You will get an acknowledgement as soon as the maintainer sees the report.
Please give a reasonable window for a fix before any public disclosure.

## Scope

Improv Toolbox is a client-side application with no user accounts and no server
of its own. The most relevant concerns are the build/deploy pipeline, bundled
dependencies, and the optional native (Capacitor) shells. Reports about any of
these are welcome.
